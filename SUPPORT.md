# Soul Buddy support

Soul Buddy is developed by [Norvan](https://github.com/norvancc). For help, [open a support issue](https://github.com/norvancc/soul-buddy/issues/new).

## Requirements

- A Mac running macOS 14 or later, with the Soul Buddy Mac app.
- An iPhone or iPad running iOS / iPadOS 15 or later, with the Soul Buddy app.
- Both devices on the same trusted private Wi-Fi or local network.
- A supported coding-agent integration on the Mac to display live agent activity.

## Get connected

1. Download the [Mac release](https://github.com/norvancc/soul-buddy/releases/latest), unzip it, and move Soul Buddy to Applications.
2. Open Soul Buddy on the Mac and follow its integration setup.
3. Open Soul Buddy on the phone and allow Local Network access when requested.
4. On the Mac, open Devices → Add device, enter the phone's six-digit code, and connect. The first-run setup can also take you directly to pairing.

## Use your companions

- Swipe left for the full-screen face; swipe right for the companion world.
- Tap a companion to bring its associated app forward on your Mac.
- Tap empty space to briefly brighten the clock.
- Hold the display for two seconds to open Reconnect, Forget Mac, About, and Close.
- Select or import themes using Themes in the Mac app.

## If devices do not connect

Keep both apps open on the same private network. Check Local Network permission in system settings. Guest Wi-Fi, network isolation, firewalls, and some VPN configurations can prevent discovery. Reopen the phone app to get a fresh pairing code if needed.

If agent activity does not appear, check Integrations on the Mac and complete the selected agent's setup. Newly installed hooks may require a new agent session or the agent's own hook review.

## Reporting a problem

Include the app versions, Mac and iOS versions, and the steps that reproduce the issue. A screenshot of the affected screen is useful. GitHub issues are public: omit passwords, pairing codes, credentials, private code, and chat content.
