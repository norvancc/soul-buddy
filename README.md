# Soul Buddy

A little presence. Right beside you.

Soul Buddy turns the activity of your AI coding agents into animated companions on your iPhone or iPad. Each active session has its own character. Swipe between a shared world and a full-screen face, or tap a companion to return to its app on your Mac.

- **Mac:** [Download the Mac installation package](https://github.com/norvancc/soul-buddy/releases/download/v1.8.6/Soul-Buddy-macOS-1.8.6-universal.zip) · macOS 14 or later · Apple Silicon and Intel.
- **iPhone and iPad:** version 1.7.6 has been submitted for App Store review. It will be free when approved.
- **Setup and support:** [Support](SUPPORT.md)
- **Privacy:** [Privacy policy](PRIVACY.md)

Install both apps, keep your devices on the same trusted private network, and enter the phone's six-digit code in the Mac app. No Soul Buddy account is required.

This repository hosts official installation packages and user documentation. Application source code is kept private and is not included here.
